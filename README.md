# 🎓 Student Management System

A Full Stack Student Management System developed using **React.js**, **Spring Boot**, **PostgreSQL**, **JWT Authentication**, and **Spring Security**.

The application allows users to register, log in securely, and perform complete CRUD operations on student records.

---

- User Registration
- User Login
- JWT Authentication
- Spring Security
- Add Student
- View Students
- Search Students
- Update Student
- Delete Student

- CSS Animations & Hover Effects

# 📌 Frontend Components

Dashboard

Displays dashboard statistics.

StudentForm

Collects student information and sends data to backend.

StudentList

Displays all students.

SearchBar

Search students by Name, Email, Course or ID.

StudentService

Contains all Axios API calls.

AuthService

Handles Login and Register API requests.

---

# 📌 Backend Layers

Controller

Receives HTTP Requests.

Service

Contains Business Logic.

Repository

Communicates with PostgreSQL using Spring Data JPA.

Entity

Represents Database Tables.

DTO

Transfers Login and Register request/response data.

JWT

Generates and validates JWT Tokens.

Security

Protects APIs using Spring Security.

# 🔄 CRUD Operations

Create Student

POST /student/save

Read All Students

GET /student/all

Read Student By ID

GET /student/{id}

Update Student

PUT /student/update/{id}

Delete Student

DELETE /student/delete/{id}

---

# 📡 REST APIs

Authentication APIs

POST /api/auth/register

Student APIs
